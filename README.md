# 🚗 DriveFleet - Car Rental Platform

DriveFleet is a modern full-stack car rental platform built with Next.js where users can explore cars, view details, book vehicles, and manage their own listings. The system includes authentication, protected routes, and a responsive UI for all devices.

## 🌐 Live Site

👉 https://drivefleet-rouge.vercel.app/

---

## ✨ Key Features

- 🔐 Secure authentication system with Firebase (Email/Password + Google Login)
- 🚗 Browse and explore available cars with dynamic data from MongoDB
- 📌 Book cars and manage bookings with real-time updates
- ➕ Add, update, and delete car listings (CRUD functionality)
- 🔍 Search and filter cars by name and type using MongoDB queries
- 🧾 Featured cars section using dynamic backend API
- 🛡️ JWT protected private routes with HTTP-only cookies
- 📱 Fully responsive design for mobile, tablet, and desktop
- ⚡ Fast performance using Next.js routing and rendering
- 🎯 Clean and recruiter-friendly UI design

## 🔐 Authentication Flow

- Users can register/login using email or Google
- JWT token stored in HTTP-only cookie
- Protected routes prevent unauthorized access
- Persistent login on page refresh

- Car booking system
